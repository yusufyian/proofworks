# 食品农产品全链路追溯平台

## 项目简介

基于区块链技术的食品农产品全链路可追溯系统，实现从产地到餐桌的全程透明化追溯。

## 技术栈

- **前端**: React 18 + TypeScript + Vite + TailwindCSS
- **后端**: Node.js + Express + TypeScript
- **数据存储**: JSON文件存储（演示用）

## 功能特性

### 核心功能
- ✅ 一物一码管理
- ✅ 产品档案管理
- ✅ 批次管理与追踪
- ✅ 流转记录可视化
- ✅ IoT数据采集（温度、GPS等）
- ✅ 消费者扫码查询
- ✅ 召回管理
- ✅ 质检报告管理
- ✅ 智能帮助系统

### 数据分析功能（新增）
- ✅ **宏观KPI仪表盘**：追溯覆盖率、合规率、召回率、温控合规率等关键指标
- ✅ **趋势分析**：批次、事件、温度等指标的时间趋势分析
- ✅ **温控合规分析**：温度分布统计、趋势曲线、异常事件分析
- ✅ **质量分析**：批次状态分布、产品类别统计、不合格项Top10、检测结果统计
- ✅ **物流绩效分析**：各环节停留时间、地点活跃度、操作员活跃度统计
- ✅ **地理热力图**：按区域统计流转事件分布
- ✅ **时间范围筛选**：支持自定义时间范围进行数据分析

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

前端地址: http://localhost:3002
后端地址: http://localhost:3022

### 构建生产版本

```bash
npm run build
```
