# 知识产权数实资产凭证与维权平台

基于区块链技术的知识产权确权存证、侵权监测、维权管理和资产交易平台。

## 功能特性

- ✅ **确权存证**：设计图纸、创意素材、技术文档等数字资产的上链存证
- ✅ **侵权监测**：AI智能识别全网平台的疑似侵权行为
- ✅ **维权管理**：从取证到诉讼的全流程维权管理
- ✅ **授权交易**：支持多种授权类型的知识产权授权与转让
- ✅ **设备台账**：实体设备的数字孪生与权属管理
- ✅ **区块链存证**：基于Hyperledger Fabric的不可篡改存证

## 技术栈

### 后端
- Node.js + Express + TypeScript
- 文件存储（JSON格式，用于演示）
- JWT认证
- 区块链模拟（哈希、交易、区块高度等）

### 前端
- React + TypeScript + Vite
- Tailwind CSS
- React Query
- Zustand状态管理
- Recharts图表

## 快速开始

### 环境要求
- Node.js >= 18
- npm 或 yarn

### 安装依赖

```bash
# 安装后端依赖
cd backend
npm install

# 安装前端依赖
cd ../frontend
npm install
```

### 启动服务

#### 启动后端（端口 3028）
```bash
cd backend
npm run dev
```

#### 启动前端（端口 3008）
```bash
cd frontend
npm run dev
```

### 访问系统
- 前端地址：http://localhost:3008
- 后端API：http://localhost:3028

## 核心功能模块

### 1. 确权存证
- 文件上传与哈希计算
- 时间戳服务（TSA）
- 区块链存证
- 存证证书生成

### 2. 侵权监测
- 全网平台爬取
- AI图像/文本相似度识别
- 证据自动取证
- 区块链证据存证

### 3. 维权管理
- 维权申请提交
- 律师审查
- 公证处公证
- 律师函发送
- 诉讼管理

### 4. 授权交易
- 多种授权类型（非独占、独占、排他等）
- NFT授权凭证
- 智能合约自动分账
- 授权期限管理

### 5. 设备台账
- 设备NFT铸造
- 全生命周期记录
- 权属变更追踪
- IoT数据集成

## 区块链特性

- **存证哈希**：SHA256文件哈希
- **交易哈希**：随机生成的64位十六进制
- **区块高度**：模拟区块链高度（1500000+）
- **时间戳**：国家授时中心时间戳（模拟）
- **可验证性**：通过交易哈希查询存证信息

## 开发说明

### 添加新功能
1. 在后端 `src/types/index.ts` 中定义类型
2. 在 `src/controllers/` 中创建控制器
3. 在 `src/routes/` 中添加路由
4. 在前端 `src/api/` 中添加API调用
5. 在前端 `src/pages/` 中创建页面

### 数据初始化
首次启动后端时，系统会自动检测数据文件是否存在。如果不存在，会自动调用 `generateMockData()` 生成模拟数据。

## 注意事项

- 本系统为演示用途，使用文件存储而非数据库
- 区块链功能为模拟实现，非真实区块链网络
- 密码使用bcrypt加密存储
- JWT token有效期7天
