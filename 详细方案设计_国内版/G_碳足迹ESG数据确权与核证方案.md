# G. 碳足迹/ESG数据确权与核证 详细方案设计

## 一、方案概述

### 1.1 业务目标
- 实现产品/企业/园区级碳足迹全生命周期核算
- 支持减排量与绿色权益（绿证、碳信用）的确权与交易
- 满足ESG信息披露要求（GRI、TCFD、ISSB等标准）
- 提供第三方可验证的碳核查与审计报告

### 1.2 核心价值
- **双碳合规**：满足国家"双碳"目标与行业减排要求
- **供应链协同**：上下游碳数据协同，产品碳足迹追溯
- **绿色金融**：碳资产确权后可质押融资、碳交易
- **品牌价值**：ESG评级提升，吸引ESG投资

### 3.1 组织碳盘查流程

```mermaid
sequenceDiagram
    participant 企业
    participant 碳盘查系统
    participant 数据采集
    participant 排放因子库
    participant 核算引擎
    participant 区块链
    participant 第三方核证
    
    企业->>碳盘查系统: 1. 设定盘查边界
    Note over 企业,碳盘查系统: 时间范围、组织边界、运营边界
    
    碳盘查系统->>数据采集: 2. 启动数据采集任务
    
    数据采集->>数据采集: 3. 采集活动数据
    Note over 数据采集: 范围1：燃煤、燃气、燃油<br/>范围2：外购电力、热力<br/>范围3：差旅、物流、员工通勤
    
    数据采集->>排放因子库: 4. 查询排放因子
    Note over 数据采集,排放因子库: 2024年全国电网平均排放因子<br/>柴油：3.0956 kgCO2/L
    
    排放因子库-->>核算引擎: 5. 返回排放因子
    
    核算引擎->>核算引擎: 6. 计算碳排放量
    Note over 核算引擎: 排放量 = 活动数据 × 排放因子
    
    loop 各排放源
        核算引擎->>核算引擎: 7. 分类汇总
        Note over 核算引擎: 按范围1/2/3、按排放源类型
    end
    
    核算引擎->>区块链: 8. 核算过程存证
    Note over 核算引擎,区块链: 活动数据哈希、因子版本、计算结果
    
    核算引擎-->>碳盘查系统: 9. 生成盘查报告
    Note over 核算引擎,碳盘查系统: 总排放量、分类明细、同比分析
    
    碳盘查系统->>第三方核证: 10. 提交核查申请
    
    第三方核证->>第三方核证: 11. 现场核查
    Note over 第三方核证: 抽查原始凭证、访谈、计算复核
    
    第三方核证->>区块链: 12. 核证报告上链
    Note over 第三方核证: 核证意见、核证标准、签章
    
    第三方核证-->>企业: 13. 出具核证报告
```

**盘查范围说明：**

| 范围 | 定义 | 排放源示例 | 数据来源 |
|-----|------|----------|---------|
| 范围1 | 直接排放 | 燃煤锅炉、公司车辆、生产工艺过程 | 能源账单、车辆油耗 |
| 范围2 | 间接排放（能源） | 外购电力、外购热力、外购蒸汽 | 电费单、热力费单 |
| 范围3 | 其他间接排放 | 采购原料、物流运输、员工差旅、产品使用 | 供应商数据、物流单 |

```mermaid

    participant LCA系统
    participant BOM系统
    participant 供应商平台
    participant 核算引擎
    participant 碳标签生成
    participant 区块链
    
    产品经理->>LCA系统: 1. 创建产品碳足迹项目
    Note over 产品经理,LCA系统: 产品名称、功能单位、系统边界
    
    LCA系统->>BOM系统: 2. 获取产品BOM
    BOM系统-->>LCA系统: 3. 返回物料清单
    Note over BOM系统,LCA系统: 原材料、零部件、数量
    
    loop 各物料
        LCA系统->>供应商平台: 4. 查询物料碳足迹

        else 供应商未提供
            LCA系统->>LCA系统: 5b. 使用数据库平均值
            Note over LCA系统: Ecoinvent/CLCD数据库
        end
    end
    
    LCA系统->>核算引擎: 6. 计算各阶段排放
    Note over LCA系统,核算引擎: 原料获取、生产制造、运输分销<br/>使用阶段、废弃处置
    
    核算引擎->>核算引擎: 7. 生产阶段核算
    Note over 核算引擎: 生产线能耗 × 产量分摊
    
    核算引擎->>核算引擎: 8. 运输阶段核算
    Note over 核算引擎: 吨公里法：重量 × 距离 × 排放因子
    
    核算引擎->>核算引擎: 9. 使用阶段核算
    Note over 核算引擎: 电器产品：功率 × 使用时长 × 电网因子
    
    核算引擎->>核算引擎: 10. 汇总全生命周期排放
    
    核算引擎->>区块链: 11. 核算结果存证
    Note over 核算引擎,区块链: 产品型号、碳足迹值、核算方法
    
    核算引擎->>碳标签生成: 12. 生成碳标签
    碳标签生成->>碳标签生成: 13. 分级评价
    Note over 碳标签生成: A级（优秀）、B级（良好）、C级（一般）
    
    碳标签生成-->>产品经理: 14. 返回碳标签图片与证书
    Note over 碳标签生成,产品经理: 可印刷在产品包装上
```

| 生命周期阶段 | 排放量（kgCO2e） | 占比 |
|------------|----------------|------|
| 原材料获取 | 35 | 43.8% |
| 生产制造 | 20 | 25.0% |
| 运输分销 | 5 | 6.2% |
| 使用阶段 | 15 | 18.8% |
| 废弃处置 | 5 | 6.2% |

**减排项目类型与减排量计算：**

| 项目类型 | 基准线 | 实际排放 | 减排量计算 |
|---------|--------|---------|----------|
| 屋顶光伏 | 电网购电排放 | 0 | 发电量 × 电网因子 |
| LED节能改造 | 改造前耗电 | 改造后耗电 | (改造前 - 改造后) × 电网因子 |
| 新能源车队 | 燃油车排放 | 电动车排放 | (燃油车油耗 × 燃油因子) - (电耗 × 电网因子) |
| 林业碳汇 | 无树木吸收 | 树木吸收CO2 | 固碳量（生物量法） |

## 四、核心功能模块

### 4.1 排放因子库

**数据来源：**
- 国家发改委《省级温室气体清单编制指南》
- 生态环境部《企业温室气体排放核算方法与报告指南》
- IPCC（政府间气候变化专门委员会）数据库
- Ecoinvent国际生命周期数据库

**因子类型：**

| 能源类型 | 排放因子 | 单位 | 数据来源 |
|---------|---------|------|---------|
| 电力（华北电网） | 0.8843 | kgCO2/kWh | 2023年区域电网 |
| 天然气 | 2.1622 | kgCO2/m³ | 国家标准 |
| 汽油 | 2.925 | kgCO2/L | 国家标准 |
| 柴油 | 3.0956 | kgCO2/L | 国家标准 |
| 煤炭（烟煤） | 1.9003 | kgCO2/kg | 国家标准 |

**动态更新机制：**
- 电网排放因子：每年更新（生态环境部发布）
- 燃料因子：每3年更新
- 版本管理：所有历史版本可追溯

### 4.2 碳核算引擎

**核算公式：**

```
基础公式：
GHG排放量 = 活动数据 × 排放因子

示例1 - 电力消耗：
排放量 = 10000 kWh × 0.8843 kgCO2/kWh = 8843 kgCO2

示例2 - 柴油车辆：
排放量 = 500 L × 3.0956 kgCO2/L = 1547.8 kgCO2

示例3 - 产品碳足迹（分摊法）：
单位产品排放 = 生产线总排放 / 总产量
             = 100 tCO2 / 10000件
             = 10 kgCO2/件
```

**复杂场景处理：**

1. **混合能源**（如汽电共生）
   ```
   净外购电排放 = 外购电量 × 电网因子
                - 余热发电量 × 电网因子
   ```

2. **物流碳足迹**（多式联运）
   ```
   总排放 = 公路运输排放 + 铁路运输排放 + 海运排放
   公路排放 = 货物重量(t) × 运输距离(km) × 0.12 kgCO2/(t·km)
   ```

3. **范围3上游排放**（采购）
   ```
   采购排放 = Σ(采购金额 × 行业排放强度)
   行业排放强度：钢材 2.1 tCO2/万元，塑料 1.5 tCO2/万元
   ```

### 4.4 供应商碳数据协同模块

**供应商门户功能：**
1. 碳数据填报（产品碳足迹、企业碳排放）
2. 数据质量检查（合理性校验）
3. 第三方核证报告上传
4. 碳绩效评分展示

**供应商碳评级模型：**

```
总分 = 碳数据透明度(30%) 
     + 碳排放强度(40%) 
     + 减排目标(20%) 
     + 可再生能源使用率(10%)

评级  | 分数      | 采购优先级
-----|-----------|-------------
A+   | 90-100    | 优先选择
A    | 80-89     | 推荐选择
B    | 70-79     | 正常选择
C    | 60-69     | 需改进
D    | <60       | 限制采购
```

**案例：**
- 苹果公司要求供应链2030年碳中和
- 戴尔要求供应商披露Scope 1+2排放
- 宜家追溯家具产品的原材料碳足迹

| 风险类型 | 风险描述 | 应对措施 |
