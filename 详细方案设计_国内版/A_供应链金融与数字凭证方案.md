# A. 供应链金融 & 数字凭证 详细方案设计

## 一、方案概述

### 1.1 业务目标
- 实现应收账款、预付账款、票据、仓单等凭证的可信数字化流转
- 支持凭证的转让、质押、融资等全生命周期管理
- 实现供应链金融业务的穿透式风控和审计
- 降低中小企业融资成本，提高资金周转效率

### 1.2 核心价值
- **可信流转**：基于联盟链的不可篡改凭证流转记录
- **穿透核验**：从核心企业到多级供应商的穿透式校验
- **融资对接**：与银行/保理公司系统对接，加速融资审批
- **风险管控**：防重复融资、反质押循环检测、额度实时监控

## 三、核心业务流程

### 3.1 凭证签发流程

```mermaid
sequenceDiagram
    participant 核心企业
    participant 凭证服务
    participant 智能合约
    participant 联盟链
    participant 供应商
    
    核心企业->>凭证服务: 1. 提交应收账款确权申请
    Note over 核心企业,凭证服务: 包含：合同、发票、验收单
    
    凭证服务->>凭证服务: 2. 材料完整性校验
    凭证服务->>凭证服务: 3. 风控规则检查
    
    凭证服务->>智能合约: 4. 调用凭证发行接口
    智能合约->>智能合约: 5. 生成凭证唯一ID
    智能合约->>智能合约: 6. 国密签名
    
    智能合约->>联盟链: 7. 写入凭证元数据
    Note over 智能合约,联盟链: 债权人、债务人、金额、到期日、状态
    
    联盟链-->>供应商: 8. 推送凭证持有通知
    凭证服务-->>核心企业: 9. 返回凭证编号与哈希
    
    供应商->>凭证服务: 10. 查询与确认
```

**关键控制点：**
1. 核心企业数字签名验证（国密SM2）
2. 凭证金额与合同、发票三单匹配
3. 唯一性校验（防重复签发）
4. 凭证状态初始化为"持有中"

### 3.2 凭证拆分与转让流程

```mermaid
sequenceDiagram
    participant 一级供应商
    participant 流转服务
    participant 转让合约
    participant 风控引擎
    participant 二级供应商
    participant 联盟链
    
    一级供应商->>流转服务: 1. 发起拆分/转让申请
    Note over 一级供应商,流转服务: 原凭证ID、拆分金额、受让方
    
    流转服务->>转让合约: 2. 查询凭证状态与余额
    转让合约-->>流转服务: 3. 返回可用额度
    
    流转服务->>风控引擎: 4. 风控检查
    Note over 流转服务,风控引擎: 防重复转让、循环质押检测
    
    风控引擎-->>流转服务: 5. 风控通过
    
    流转服务->>转让合约: 6. 执行转让交易
    转让合约->>转让合约: 7. 原凭证拆分/核销
    转让合约->>转让合约: 8. 生成新凭证给受让方
    
    转让合约->>联盟链: 9. 记录转让事件
    Note over 转让合约,联盟链: 转让方、受让方、金额、时间戳
    
    联盟链-->>二级供应商: 10. 推送持有通知
    流转服务-->>一级供应商: 11. 转让成功确认
```

**关键控制点：**
1. 转让方持有凭证有效性校验
2. 拆分金额不超过凭证可用余额
3. 受让方身份合规性检查
4. 转让链路穿透记录（追溯到核心企业）
5. 防止循环转让（图算法检测环路）

### 3.3 凭证质押融资流程

```mermaid
sequenceDiagram
    participant 供应商
    participant 融资服务
    participant 质押合约
    participant 风控引擎
    participant 银行系统
    participant e-CNY接口
    participant 联盟链
    
    供应商->>融资服务: 1. 提交融资申请
    Note over 供应商,融资服务: 凭证ID、融资金额、期限
    
    融资服务->>质押合约: 2. 查询凭证状态
    质押合约-->>融资服务: 3. 凭证可质押
    
    融资服务->>风控引擎: 4. 融资风控评估
    Note over 融资服务,风控引擎: 核心企业信用、凭证真实性<br/>历史违约率、供应商资质
    
    风控引擎->>风控引擎: 5. 穿透式风控
    风控引擎->>联盟链: 6. 查询完整转让链路
    联盟链-->>风控引擎: 7. 返回追溯路径
    
    风控引擎-->>融资服务: 8. 风控评分与建议额度
    
    融资服务->>银行系统: 9. 推送融资请求
    银行系统->>银行系统: 10. 人工/自动审批
    
    银行系统-->>融资服务: 11. 审批通过
    
    融资服务->>质押合约: 12. 执行质押锁定
    质押合约->>联盟链: 13. 记录质押事件
    Note over 质押合约,联盟链: 质押方、质权人、金额、期限
    
    银行系统->>e-CNY接口: 14. 发起放款
    e-CNY接口-->>供应商: 15. 数字人民币到账
    
    e-CNY接口->>融资服务: 16. 回调支付凭证
    融资服务->>联盟链: 17. 记录放款事件
    融资服务-->>供应商: 18. 融资成功通知
```

**关键控制点：**
1. 凭证未被质押/转让状态检查
2. 穿透式风控：验证到核心企业的完整链路
3. 质押冻结期间凭证不可转让
4. 放款与质押原子性（事务保证）
5. e-CNY 支付回单关联存证

### 3.4 凭证到期清算流程

```mermaid
sequenceDiagram
    participant 定时任务
    participant 清算服务
    participant 智能合约
    participant 核心企业
    participant e-CNY接口
    participant 银行
    participant 供应商
    participant 联盟链
    
    定时任务->>清算服务: 1. 扫描到期凭证
    清算服务->>智能合约: 2. 查询凭证详情
    智能合约-->>清算服务: 3. 返回到期凭证列表
    
    清算服务->>核心企业: 4. 推送还款通知
    核心企业->>e-CNY接口: 5. 发起还款
    
    alt 无质押
        e-CNY接口-->>供应商: 6a. 直接付款
    else 有质押
        e-CNY接口-->>银行: 6b. 先还银行
        银行->>智能合约: 7. 触发解质押
        智能合约->>联盟链: 8. 记录解质押事件
        银行->>e-CNY接口: 9. 付款给供应商
        e-CNY接口-->>供应商: 10. 剩余款项到账
    end
    
    清算服务->>智能合约: 11. 核销凭证
    智能合约->>联盟链: 12. 凭证状态→已清算
    
    清算服务->>联盟链: 13. 记录清算事件
    清算服务-->>核心企业: 14. 清算完成通知
    清算服务-->>供应商: 15. 收款确认通知
```

**关键控制点：**
1. 到期日自动触发清算流程
2. 质押凭证优先还款给质权人
3. 支付顺序：银行本息 → 担保费用 → 供应商余额
4. 凭证核销后不可再次使用
5. 全流程审计日志留存

## 四、核心功能模块

### 4.1 凭证智能合约模块

**主要功能：**
- 凭证发行（Issue）
- 凭证拆分（Split）
- 凭证转让（Transfer）
- 凭证质押（Pledge）
- 凭证解质押（Unpledge）
- 凭证核销（Redeem）
- 状态查询（Query）

**数据结构：**
```
凭证对象 {
  凭证ID: string
  原始凭证ID: string (拆分后)
  债权人: string (核心企业)
  债务人: string (当前持有人)
  初始金额: decimal
  剩余金额: decimal
  签发日期: timestamp
  到期日期: timestamp
  状态: enum (持有中|已转让|已质押|已核销)
  转让历史: array
  质押信息: object
  合同哈希: string
  发票哈希: string
  国密签名: string
}
```

**状态机：**
```
初始化 → 持有中 → [转让/拆分] → 持有中
                 ↓
               已质押 → 解质押 → 持有中
                 ↓
               到期 → 已核销
```

---

### 4.2 风控引擎模块

**核心规则：**

1. **防重复融资规则**
   - 检查凭证是否已质押
   - 跨平台黑名单查询（征信接口）
   - 历史融资记录去重

2. **循环质押检测**
   - 图算法检测转让链路中的环路
   - 关联企业持股关系穿透
   - 异常转让频率告警

3. **额度风控**
   - 核心企业总授信额度控制
   - 单笔凭证融资比例限制（如70%）
   - 供应商融资余额上限

4. **真实性校验**
   - 三单匹配：合同+发票+验收单
   - 核心企业确权接口回调
   - 历史贸易背景审查

**风控评分模型：**
```
总分 = 核心企业评级(40%) 
     + 凭证真实性(30%) 
     + 供应商资质(20%) 
     + 历史履约率(10%)

评级  | 分数      | 建议融资比例
-----|-----------|-------------
AAA  | 90-100    | 80%
AA   | 80-89     | 70%
A    | 70-79     | 60%
BBB  | 60-69     | 50%
拒绝  | <60       | 0%
```

---

### 4.3 穿透式审计模块

**审计维度：**

1. **凭证生命周期审计**
   - 签发 → 转让 → 质押 → 清算全流程
   - 每步操作人、时间戳、IP地址
   - 国密签名验证记录

2. **资金流审计**
   - e-CNY 支付回单关联
   - 放款 → 还款闭环追踪
   - 资金分账明细（本金、利息、手续费）

3. **风险事件审计**
   - 逾期事件记录
   - 异常转让告警
   - 风控拒绝原因留存

**审计报表输出：**
- 按核心企业维度：授信使用率、逾期率
- 按供应商维度：融资笔数、平均利率
- 按银行维度：放款规模、不良率
- 按时间维度：日报、月报、季度报

## 六、部署架构

### 6.1 联盟链网络拓扑
```
核心企业节点 (Orderer)
    ↓
├── 银行1节点 (Peer + Endorser)
├── 银行2节点 (Peer + Endorser)
├── 保理公司节点 (Peer)
├── 担保公司节点 (Peer)
└── 平台运营节点 (Peer + CA)
```

### 6.2 高可用部署
- 应用服务：K8s 多副本（≥3）
- 数据库：PostgreSQL 主从复制
- 联盟链：多组织多节点（≥4）
- 缓存层：Redis Cluster

### 6.3 安全加固
- 国密SSL通信（SM2证书）
- API网关鉴权（OAuth2.0）
- 敏感数据加密存储（SM4）
- 密钥托管（HSM硬件加密机）
