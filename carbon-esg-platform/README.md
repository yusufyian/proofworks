# 碳足迹/ESG数据确权与核证平台

## 项目简介

基于区块链技术的碳足迹和ESG数据确权与核证平台，支持组织碳盘查、产品碳足迹、减排项目管理和ESG报告生成。

## 技术栈

- **前端**: React 18 + TypeScript + Vite + TailwindCSS
- **后端**: Node.js + Express + TypeScript
- **数据存储**: JSON文件（用于演示）

## 功能模块

1. **组织碳盘查**: 范围1/2/3碳排放核算与管理
2. **产品碳足迹**: 基于LCA的生命周期碳排放评价
3. **减排项目**: CCER等碳资产管理
4. **ESG报告**: 符合GRI、TCFD等国际标准
5. **数据确权**: 区块链存证与核证

## 快速开始

### 1. 安装依赖

```bash
npm run install:all
```

### 2. 生成模拟数据

```bash
cd backend
npm run seed
```

这将生成：
- 30家公司
- 60+用户
- 360+条碳盘查记录（过去12个月）
- 150+个产品碳足迹
- 90+个减排项目
- 90+份ESG报告
- 150+条供应商碳数据

### 3. 启动后端服务

```bash
cd backend
npm run dev
```

后端服务运行在 http://localhost:3027

### 4. 启动前端服务

```bash
cd frontend
npm run dev
```

前端服务运行在 http://localhost:3007

### 5. 登录系统

使用seed脚本生成的用户账号登录：
- 默认密码：`123456`
- 可以在后端日志中查看生成的邮箱地址

2. 所有密码使用bcrypt加密存储

4. 模拟数据包含逼真的中文人名和公司名
