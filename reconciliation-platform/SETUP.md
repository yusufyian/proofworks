# 结算对账自动化平台 - 设置说明

## 端口配置

- **前端端口**: 3004
- **后端端口**: 3024

前端会自动通过代理连接到后端API（`/api` 路径会代理到 `http://localhost:3024`）。

如需修改端口，请编辑：
- 前端端口：`frontend/vite.config.ts` 中的 `server.port`
- 后端端口：`backend/src/index.ts` 中的 `PORT` 或设置环境变量 `PORT`

## 数据初始化说明

如果页面显示数据为0或空，请按照以下步骤操作：

## 步骤1：生成模拟数据

在项目根目录下运行：

```bash
cd backend
npm run seed
```

这将生成最近30天的模拟数据，包括：
- 业务流水记录
- 支付流水记录
- 对账记录
- 差异工单
- 清分记录

**注意**：数据生成可能需要几分钟时间，请耐心等待。

## 步骤2：确认数据文件

检查 `backend/data/storage.json` 文件是否存在，并且文件大小不为0。

如果文件不存在或为空，请重新运行 `npm run seed`。

## 步骤3：重启后端服务

生成数据后，重启后端服务：

```bash
cd backend
npm run dev
```

## 步骤4：刷新前端页面

在前端页面刷新浏览器，数据应该就能正常显示了。

## 验证数据

如果数据生成成功，你应该能看到：
- 仪表盘显示今日交易笔数、对平率等统计数据
- 趋势图表显示最近7天或30天的数据
- 渠道分布图显示各支付渠道的占比
- 对账管理页面显示对账记录列表
- 差异处理页面显示差异工单列表

## 常见问题

### Q: 运行seed后还是看不到数据？
A: 检查后端控制台是否有错误信息，确保数据文件路径正确。

### Q: 数据文件在哪里？
A: 数据文件位于 `backend/data/storage.json`

### Q: 可以重新生成数据吗？
A: 可以，删除 `backend/data/storage.json` 文件后重新运行 `npm run seed`
