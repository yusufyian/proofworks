# 结算对账自动化平台

一个基于 React + Node.js 的结算与对账自动化平台，支持多支付渠道自动对账、差异处理、资金清分等功能。

## 功能特性

- ✅ **多渠道对账**：支持微信支付、支付宝、银行卡、数字人民币（e-CNY）等多种支付渠道
- ✅ **自动匹配**：智能匹配业务流水与支付流水，支持多种匹配规则
- ✅ **差异处理**：自动识别和处理长款、短款、金额差异等情况
- ✅ **资金清分**：支持订单金额的多账户清分，包括平台服务费、支付手续费等
- ✅ **区块链存证**：所有对账和清分记录上链存证，确保可追溯性
- ✅ **实时监控**：实时展示对账统计、差异统计等关键指标
- ✅ **帮助提示**：每个重要功能都配有详细的帮助说明

## 技术栈

### 后端
- Node.js + Express
- TypeScript
- 文件存储（JSON格式）

### 前端
- React 18
- TypeScript
- Tailwind CSS
- Recharts（图表）
- React Query（数据获取）
- Zustand（状态管理）

## 快速开始

### 1. 安装依赖

```bash
# 安装所有依赖（包括前后端）
npm run install:all

# 或者分别安装
cd backend && npm install
cd ../frontend && npm install
```

### 2. 生成模拟数据

```bash
cd backend
npm run seed
```

这将生成最近30天的模拟数据，包括：
- 业务流水记录（POS、电商、O2O等）
- 支付流水记录（微信、支付宝、银行卡、e-CNY）
- 对账记录
- 差异工单
- 清分记录

**注意**：数据生成可能需要几分钟时间，请耐心等待。

### 2.1 检查数据状态（可选）

如果页面显示数据为空，可以运行以下命令检查数据：

```bash
cd backend
npm run check
```

这会显示数据文件的统计信息，帮助诊断问题。

### 3. 启动开发服务器

```bash
# 在项目根目录运行，同时启动前后端
npm run dev

# 或者分别启动
# 后端（端口3024）
cd backend && npm run dev

# 前端（端口3004）
cd frontend && npm run dev
```

### 4. 访问应用

打开浏览器访问：http://localhost:3004

- 邮箱：`admin@reconciliation.com`

## 主要页面

### 1. 仪表盘（Dashboard）
- 展示今日交易统计、对平率等关键指标
- 趋势分析图表（7天/30天）
- 渠道分布饼图

### 2. 对账管理（Reconciliation）
- 查看对账记录
- 手动触发对账任务
- 筛选和分页查看

### 3. 差异处理（Discrepancy）
- 查看差异工单列表
- 更新工单状态
- 按类型和状态筛选

### 4. 清分管理（Settlement）
- 查看清分记录
- 查看清分明细
- 查看区块链交易哈希

## 数据说明

### 业务流水
- 来源：POS、电商、O2O、会员充值、企业采购
- 字段：订单号、金额、支付方式、门店、操作员等

### 支付流水
- 渠道：微信支付、支付宝、银行卡、数字人民币
- 字段：商户订单号、渠道订单号、实付金额、手续费等

### 对账记录
- 匹配状态：已对平、未匹配、待处理
- 匹配规则：精确匹配、订单号匹配、金额时间匹配

### 差异工单
- 类型：长款、短款、金额差异、时间差异
- 状态：待处理、处理中、已解决、已关闭

## 注意事项

1. **演示用途**：本项目仅用于演示，使用文件存储而非数据库
2. **数据生成**：首次运行需要执行 `npm run seed` 生成模拟数据
3. **端口配置**：后端默认3024，前端默认3004，可在配置文件中修改
4. **帮助提示**：每个重要功能都有帮助图标（❓），点击可查看详细说明
